# BIF artwork

- `bif-logo.png`: original generated portrait.
- `favicon-16.png`, `favicon-32.png`: small browser icons.
- `favicon.ico`: 32-pixel ICO browser icon.

Created with the built-in image generation tool. The application currently has no web frontend; these favicon files are ready for a future web UI.

## Generation prompt

Use case: logo-brand. Create a square pixel-art portrait logo and favicon for BIF (Before I Forget), a task ledger application. Subject: young 1955 Biff Tannen from Back to the Future, recognizable blond swept-back flat-top hair, broad square face, strong brow and cocky scowl, tiny suggestion of jacket collar. Composition: a single centered head filling most of the square, front view with slight three-quarter character, generous small margin. Style: authentic highly simplified 32-by-32 pixel sprite enlarged with perfectly sharp square pixel edges, small restrained color palette, bold dark outline, broad readable clusters, no gradients or smoothing. Warm blond hair and peach skin, dark jacket, solid deep navy square background. Must read at favicon size. No text, no letters, no movie logo, no extra objects, no border, no mockup. Output one finished icon only.
